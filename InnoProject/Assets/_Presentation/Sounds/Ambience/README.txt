Эмбиенс игры: 4 бесшовные петли по 16 с, от спокойной к самой тревожной (как страницы в Slender).
Играет компонент Ambience на объекте Game сцены Office:
- уровни 1-2: Stage1;
- уровни 3-4: Stage2;
- уровни 5-6: Stage3;
- уровни 7-8: Stage4.
После ошибки снова Stage1. На выходе эмбиенс затихает, во время погони бабайки приглушён.
Пороги задаёт поле stageFromLevel, общую громкость — поле volume.

Источник: "Slender Game Ambience" (Lawrence Fox), файл Game Ambience.mp3, 8 минут.
Трек состоит из 4 частей примерно по 2 минуты, и каждая часть — одна 8-секундная петля.
Из середины каждой части вырезано по две такие петли с точностью до сэмпла.
Громкость частей выровнена: -22, -19.5, -17.5 и -16 LUFS (в исходнике -24, -16, -12, -12).
